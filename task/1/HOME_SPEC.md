# Sales Machine — головна сторінка «Скручена драбина»: ТЗ на верстку

> Для Claude Code. Поклади поруч `spiral-prototype.html` — це робочий прототип і **еталон руху**.
> Якщо щось у цьому ТЗ розходиться з прототипом, правильний прототип (з пресетом «Мій пресет»).
> Панель налаштувань прототипу — інструмент підбору, на продакшн вона НЕ переноситься.

---

## 0. Контекст

- Сайт: sales-machine.team, маркетингова агенція з методологією «Иммерсивный маркетинг».
- Сайт перезбирається з Webflow на код (Next.js). Ця задача — **лише головна сторінка**.
- Концепція: головна — це не лендінг, а меню-стрічка. 12 напрямів стоять у вертикальну
  «скручену драбину», яка нескінченно крутиться від скролу.
- Мова контенту — російська. Палітра — строго монохром.

## 1. Стек

- Next.js (App Router, актуальна стабільна версія) + TypeScript.
- Стилі: CSS Modules (або Tailwind, якщо вже є в проєкті) + CSS-змінні для теми.
- Анімація стрічки — власний цикл на `requestAnimationFrame` (можна через `gsap.ticker`,
  якщо GSAP уже підключено для інших сторінок). **Lenis і нативний скрол тут не потрібні.**
- Тема — `next-themes` (атрибут `data-theme` на `<html>`, без мерехтіння при завантаженні).
- Шрифт: Gilroy Medium 500 через `next/font/local` (файли шрифту надає клієнт).
  Поки ліцензованих файлів немає — Manrope 500 з `next/font/google` (subset cyrillic).

## 2. Що на екрані

1. Вертикальна стрічка з 12 пунктів, вирівняна по лівому краю, відступ зліва 9% ширини.
2. Тонка вертикальна вісь по лівому краю стрічки (лінія 1px, `currentColor`, opacity 0.18).
3. Номери 01–12 моноширинним шрифтом 12px ліворуч від осі (на 34px), навпроти першого рядка кожного пункту.
4. Зона фокусу — горизонталь на 40% висоти екрана. Пункт, що в ній, — активний.
5. Праворуч від зони фокусу — інфоблок: «04 / 12 ———» (моно 12px, сірий) і під ним підзаголовок
   активного пункту (18px / 1.35, max-width 300px).
6. Перемикач теми — **правий верхній кут** (top 18px, right 24px): підпис «Тёмная тема» /
   «Светлая тема» + повзунок-перемикач 38×22px.
7. Більше нічого: ні хедера, ні футера, ні кнопок.

## 4. Конфіг (погоджені значення)

```ts
// components/spiral/config.ts
export const SPIRAL = {
  smooth: 0.02,      // lerp-коефіцієнт згладжування скролу за кадр (менше = плавніше)
  wheelSens: 0.9,    // множник deltaY колеса
  inertia: 14,       // множник швидкості після відпускання свайпу/перетягування
  snap: true,        // доводка найближчого пункту в зону фокусу після зупинки
  snapDelay: 160,    // мс простою перед доводкою
  dir: -1,           // напрямок: 1 = колесо вниз → стрічка їде вгору; -1 = навпаки (погоджено -1)
  twist: 21,         // ° повороту на кожен «крок» від зони фокусу
  twistDir: -1,      // знак закруту (погоджено -1, «дзеркально»)
  maxAngle: 90,      // ° межа повороту; на ±90 рядок ребром і прихований
  skew: 20,          // ° skewY при |кут| = 90 (лінійно від 0)
  focus: 0.40,       // зона фокусу, частка висоти viewport
  fontSize: 90,      // px на desktop; на вузьких: min(90, 13vw)
  step: 125,         // px між пунктами при fontSize 90 (масштабується разом з fontSize, мін. 0.9·fs)
  lineGap: 0.95,     // відстань між рядками одного пункту, × fontSize
  left: 0.09,        // відступ стрічки зліва, частка ширини
  weight: 500,
  tone: true,        // колір рядка від ink (0°) до grey (maxAngle)
  blur: true,        // blur(0…2.2px) пропорційно куту
  hover: { dim: 0.2, unwind: 0, ease: 0.06 },
  theme: { ease: 0.07 }, // швидкість переходу кольорів стрічки при зміні теми
} as const;
```

## 5. Палітра й тема

| Токен | Світла | Темна |
|---|---|---|
| `--bg` | `#FFFFFF` | `#0E0E0F` |
| `--ink` (рядок у фокусі, текст) | `#181819` (24,24,25) | `#F2F2F2` (242,242,242) |
| `grey` (рядок під макс. кутом) | `#C8C8CA` (200,200,202) | `#525255` (82,82,85) |
| `back` (до чого сіріють інші при hover) | `#DEDEE0` (222,222,224) | `#343437` (52,52,55) |
| `--mute` (номер у інфоблоці) | `#8A8A8C` | `#7D7D80` |

- Фон і DOM-тексти (номери, інфоблок, перемикач) — CSS `transition: background/color .6s ease`.
- Кольори рядків стрічки рахуються в циклі кадру, тому їх треба **плавно інтерполювати**:
  `themeMix += (target - themeMix) * 0.07`, де target 0 (світла) / 1 (темна);
  кожен колір = lerp(світлий, темний, themeMix). Так стрічка міняє тему разом із фоном.
- Тема за замовчуванням — системна (`prefers-color-scheme`), вибір користувача зберігається.

## 6. Алгоритм стрічки (порт з прототипу)

### 6.1 Розкладка (перераховується при resize і зміні шрифту)

```
fs   = min(fontSize, vw * 0.13)
step = max(stepCfg * fs / fontSize, fs * 0.9)
rows = []; acc = 0
для кожного пункту i:
  lines = label.split("\n"); first = acc
  для кожного рядка l:
    rows.push({ i, text, off: acc, first: l === 0 })
    acc += (l < lines.length - 1) ? fs * lineGap : step
  itemCenter[i] = (first + first + (lines.length-1)*fs*lineGap) / 2 + fs/2
L = acc                       // довжина одного циклу
```

### 6.2 Стан руху

- `target` — куди їдемо (px «світових» координат), `cur` — де зараз.
- Щокадру: `cur += (target - cur) * smooth`; якщо |target − cur| < 0.01 → `cur = target`.
- Нативного скролу немає: `overflow: hidden` на сцені, `touch-action: none`.

### 6.3 Ввід

- **Колесо**: `wheel` з `{ passive: false }`, `preventDefault()`. Нормалізація:
  deltaMode 1 → ×16, deltaMode 2 → ×vh. `target += deltaY * wheelSens * dir`.
- **Тач / перетягування мишею** (pointer events + `setPointerCapture`):
  `dy = lastY - clientY`, `target += dy * dir`. Швидкість згладжувати:
  `vel = vel*0.6 + (dy/dt)*16*0.4`. На `pointerup`, якщо останній рух був < 80 мс тому:
  `target += vel * inertia * dir`.
- **Клавіатура**: ↓ / PageDown / Space — до наступного пункту, ↑ / PageUp — до попереднього
  (з урахуванням `dir`). Цільова позиція = центр сусіднього пункту в зоні фокусу.
- Після кожного вводу: `lastInput = now`, `snapped = false`.

### 6.4 Доводка (snap)

Якщо `snap && !snapped && !dragging && now - lastInput > snapDelay`:
`target = nearestCenter(target)`; `snapped = true`, де

```
nearestCenter(t): серед c ∈ [⌊t/L⌋-1 … ⌊t/L⌋+2], i ∈ items
  want = c*L + itemCenter[i] - vh*focus
  повернути want, найближчий до t
```

### 6.5 Рендер (щокадру)

Видимі цикли: `c` від `⌊(cur - m)/L⌋` до `⌊(cur + vh + m)/L⌋`, `m = fs * 2.5`.
Для кожного рядка `r` у кожному циклі `c`:

```
y      = c*L + r.off - cur                       // верх рядка на екрані
пропустити, якщо y < -m або y > vh + m
center = y + fs/2
d      = (center - vh*focus) / step              // скільки «кроків» від фокусу (+ нижче)
a      = clamp(-d * twist, -maxAngle, maxAngle) * twistDir
h      = hover-підсвітка пункту (0…1, див. 6.6);  a *= (1 - h*hover.unwind)
skew   = |a| / 90 * skewCfg
t      = |a| / maxAngle                          // 0 рівний … 1 ребром
transform: translate3d(left, y, 0) rotateY(a deg) skewY(skew deg)
transform-origin: 0 50%   (петля по лівому краю)
visibility: hidden, якщо |a| ≥ 89.6
колір  = tone ? lerp(ink, grey, t) : ink
blur   = blur ? t * 2.2 px : 0                   // filter: blur(), вимикати при < 0.02
```

Hover (6.6) поверх цього: `колір = lerp(колір, back, dim*dimMix*(1-h))`, далі
`колір = lerp(колір, ink, h)`, `blur *= (1 - h)`.

Номер пункту (лише для `r.first`): `translate3d(left - 34, center - 6, 0)`,
opacity `1 - min(1,|a|/90)*0.85` (+ ті самі hover-правила).

Активний пункт = пункт, чий `c*L + itemCenter[i] - cur` найближчий до `vh*focus`.
При hover активним для інфоблока стає наведений пункт.

**Важливо для продуктивності:**
- Пул DOM-вузлів (≈ видимі рядки + запас), перевикористовувати; текст міняти тільки коли
  змінився ключ `${c}_${r}`. Жодного React-стану в циклі кадру — тільки `ref` і пряме
  `element.style`.
- Анімуються лише `transform`, `color`, `filter`, `opacity`.
- Цикл ставити на паузу при `document.hidden`.

### 6.6 Hover

- Наведений пункт визначати `document.elementFromPoint(mouseX, mouseY)` → найближчий
  `[data-item-key]` (ключ `${c}_${i}`, спільний для всіх рядків пункту).
- Кожен пункт має свою підсвітку `h` у `Map`: щокадру `h += ((key === hovered ? 1 : 0) - h) * ease`,
  видаляти з Map при h < 0.002. Так при переході між словами нічого не стрибає.
- `dimMix += ((hovered ? 1 : 0) - dimMix) * ease * 0.8` — наскільки сіріють усі інші.
- Hover лише для `pointer: fine` (на тачі вимкнено).

### 6.7 Інфоблок

- Позиція: x = `max(left + fs*4.2, vw*0.55)` (але ≤ vw − 320), y = `vh*focus - 14`.
  На ширині < 640px — під зоною фокусу: x = left, y = `vh*focus + fs*0.75`.
- При зміні активного пункту: оновити текст і перезапустити анімацію появи:
  `from { opacity:0; transform: translateY(14px) rotateX(-40deg) } → to { none }`,
  550 мс, `cubic-bezier(.2,.8,.2,1)`.

### 6.8 Клік

- Клік (переміщення pointer < 6px) по рядку → перехід на `href` пункту (`router.push`).
- Перетягування не має викликати клік.

## 7. Доступність і SEO

- `<h1>` є в HTML, але прихований візуально (`.sr-only`): «Sales Machine — иммерсивный маркетинг».
- Окремо від анімованої стрічки — семантичний `<nav aria-label="Направления">` з `<ul>` із 12
  справжніх `<a href>` (візуально прихований, але фокусований з клавіатури). Анімовані
  рядки — `aria-hidden="true"`.
- Фокус клавіатурою на посиланні з цього `<nav>` → стрічка доводить відповідний пункт у фокус;
  Enter — перехід.
- `prefers-reduced-motion: reduce` → без закруту й розмиття (twist = 0, blur off),
  smooth = 0.2, стрічка лишається нескінченною.
- Перемикач теми — `<button aria-pressed>` з текстовим підписом.


## 9. Критерії приймання

- [ ] Стрічка поводиться як «Мій пресет» у `spiral-prototype.html`: та сама плавність,
      доводка, кути, нахил, тон, розмиття (порівняти поруч на 1440×900).
- [ ] Нескінченна в обидва боки, без видимого «шва» і без стрибків після кількох хвилин скролу.
- [ ] «Иммерсивный» і «маркетинг» закручуються окремо, але клік/номер/доводка — як для одного пункту.
- [ ] Hover: наведений пункт плавно чорніє й стає різким у будь-якій позиції, інші плавно сіріють;
      перехід між словами без стрибків.
- [ ] Перемикач теми в правому верхньому куті; стрічка, фон і тексти змінюють тему разом (~0.6 с);
      вибір зберігається; без мерехтіння при перезавантаженні.
- [ ] Колесо миші, тачпад, свайп на iOS/Android, клавіатура ↑/↓ — працюють.
- [ ] 60 fps на MacBook Air M1 / середньому Android; жодних layout thrashing у профайлері.
- [ ] Mobile 390px: fs ≈ 51px, інфоблок під зоною фокусу, нічого не обрізається.
- [ ] Lighthouse: Accessibility ≥ 95, h1 і nav з посиланнями присутні в HTML (SSR).
